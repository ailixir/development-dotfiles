Done 2026-10-24/25 in a scratch rsync copy (`scratchpad/g4/{base,work,basefull}`), patch applied to the real tree at the end. V26 is the migration.

- **Mechanism evidence.** Playwright `context.route('**/*')` sees only the FIRST hop of a redirect chain (the 302 target never reaches the handler; the existing origin allowlist therefore never saw hops) and sees hostnames, not resolved IPs. So the guard is a loopback forward proxy (`studio-runner/src/run/egressGuard.ts`): Chromium `proxy:{server, bypass:'<-loopback>'}` (without `<-loopback>` Chromium connects to loopback directly), proxy resolves, checks every answer, dials the checked IP (one resolve, no rebind). It must try the checked addresses in order (`localhost` resolves to ::1 first; a first-address-only dial gave 502 in secret-login fixtures). Plain-http denial = 403 with a text body (page loads it); https denial = failed CONNECT.
- **Local-run signal** = runner bound to loopback (`STUDIO_RUNNER_HOST` 127.0.0.1/::1/localhost; dev.sh and studio-local-tls.mjs set it). The replay child gets it as `CHECKS_EGRESS_LOCAL_RUN=1` (child env is an allowlist). `vitest.fixtures.config.ts` sets `STUDIO_RUNNER_HOST=127.0.0.1` so fixtures-tier loopback servers work. `objectStoreProvider=filesystem|local` is NOT a safe signal (UAT uses it). **Harness trap:** `isLocalRun` reads `process.env`, but the ReplayIT `ordinary.mjs` builds its launcher from a config OBJECT, so the script must set `process.env.STUDIO_RUNNER_HOST='127.0.0.1'` itself (symptom: replay TIMEOUT / TARGET_DRIFT with the loopback fixture refused).
- **Repo rules the guard tripped:** `test/no-dynamic-evaluation.test.ts` forbids `(async () =>` in src (no async IIFE: use named async fn + `.catch`); `guidedMode.test.ts` forbids `createServer` from node:http in src (exempted exactly `src/run/egressGuard.ts`, asserts listen on 127.0.0.1).
- **Contract reseal after removing scope/policy fields** (scripts in `scratchpad/g4/g4-reseal.cjs`, derived from the r057 merkle-reseal): besides node-hash fixpoint it needs derived preimages: `policyDecisionHash = hash({scopeHash, preparation: proof, requestDigest: hash(proposal)})` per action/excluded attempt, `admissionProvenanceHash = hash(actions.map({coordinate,admission,operationHash,scopeHash}))`, version-header `authoredInputsHash = hash({schemaVersion,sessionId,scopeHash,sourceRevision,configurationRevision,inputs[0..inputCount)})` (inputs live in `authority.privateInputs`, so pair at the `{basis,authority}` node), observation-refresh `callbackKey='oref-'+hash({identity,idempotencyKey,requestDigest})`; fixtures.json case patches with hex values need recompute from the patched sample; `test/helpers/incrementalNegativeBoundaries.ts` holds 72 oldHash/newHash literals (recompute by pointer, JSON array between `negativeBoundaries=` and `];`). Drop cases for removed concepts in the transform, on BOTH base and new copies, or `pair()` misaligns. A resealed `observedChoice` fixture moves the pinned `artifactHash` literal in `ObservedArtifactLowererTest`.
