From STUDIO-OBS-009 W3 lane B-W3 (2026-10-18). Receipt: `docs/qa/evidence/STUDIO-OBS-009/execution-20261018/b/w3/receipt.md`; recipes in `b/w3/recipes/`.

- **Pause an ordinary run before Ready through the harness (no createApplication):** `Builder.preload(js)` with a prelude that patches `childProcess.fork` (`import cp from 'node:child_process'`, replace `cp.fork`, call `syncBuiltinESMExports()`) so `dist/run/child.js` is forked from a wrapper `.mjs`. The wrapper imports `startChild`, `loadObservedBuild` and `playwrightBrowserFactory` from dist, wraps `handle.observedInitialContextMatches` (waits while `initial-context-state.json` says pause, writes an `entered` marker) and calls `startChild(process, {observedBuild})`. `loadObservedBuild()` works in the child because the launcher copies `STUDIO_RUNNER_OBSERVED_CATALOG_FILE` and `..._IMAGE_DIGEST` into its env.
- **A runner 4xx on `POST /v2/runs` leaves no log line** (validation refusals return `{code}` silently; the dispatcher only audits `DISPATCH_REFUSED`). Patch `http.ServerResponse.prototype.end` in the same prelude to append method/path/status/body to a trace file and print it in the failure message.
- **Making the fixture's synthetic observed revision runnable on the real runner:** Spring catalog = `[REAL entry, fixture entry]` (the binding takes the first entry matching the profile; the fixture published under its own build). REAL entry = node script over `dist/validator/observedReferencePolicy.js` + `dist/runtime-versions.json` (copy from `GuidedPublicationReplayIT`), image digest any 64 hex passed to the runner. The runner's policy file needs unique `policyId:version`, so give it ONLY the run's environment's policy (the fixture lists 8 under one id). `FakeStudioVaultProvider.rotate` gives a secret no origins and the job schema needs `minItems:1`: call `bindOrigins`. Replay callbacks use Node fetch: `server.ssl.client-auth=want` plus `NODE_EXTRA_CA_CERTS` = the test CA.
- **Real runner pre-Ready FINAL has no `secretUse`**, so `replayTerminal` writes `UNKNOWN_OUTCOME` (not NOT_USED). `FINALIZING` closes to `DONE` inside the FINAL (`afterFinal`) when the report carries a non-PROCESSING video status; no separate evidence callback is needed in that path.
- **Guided joined proof:** trim `GuidedFocusMutationJoinedIT`'s scaffold; add the evidence beans and `service.installPresentation(new GuidedPublicPresentationProjector(jdbc, C))` (without it `sessions.read(user,id,"result")` throws RUNTIME_INCOMPATIBLE). A pending append is SQL (`continuation MATERIALIZE` + the UPDATE) then `runnerContext`; never pushing it is the hold. SIGKILL of the session's Chromium gives a recording fact `UNAVAILABLE` and no video; for a playable recording end the session with `sessions.cancel(user, id, key, {schemaVersion:3, reason:"userRequested"})` (runner closes in order, `STORED`). `GuidedSessionVideoController` and `VideoObjectServer` are constructible in a test over `LocalVideoObjectStore`.
- **Playwright's ffmpeg (`~/Library/Caches/ms-playwright/ffmpeg-1011/ffmpeg-mac`) has no null or rawvideo muxer:** decode with `-i f.webm -c:v libvpx -f webm out.webm` (frame count in the last `frame=` line), seek with `-ss <s>` before `-i`.
- **Lock waits were 44, 22 and 4 minutes** (a ReplayIT lane held it); queue the run in the background early, do javac/gjf pre-checks outside the lock (`recipes/javac-check.sh`, `testcp.sh`), and do not edit sources between queueing and the lock being acquired. A collector run of the 3 joined cases takes ~40 s once the lock is free.
- Test classes leave `/var/folders/.../T/guided-evidence-pending-append-*` and `pre-ready-revocation-joined-*` (test CA, a fixture JWT); delete your own after copying value-free logs.

**Why:** each of these cost a lock-wait round (up to 45 min). **How to apply:** any later joined IT against the folded runner. Related: [[tooling-obs009-lane-i-scratch-emit-recipe]], [[tooling-obs009-w2-backend-lane-recipes]], [[tooling-javac-precheck-outside-lock]].
