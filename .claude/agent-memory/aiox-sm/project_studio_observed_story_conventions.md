STUDIO-OBSERVED wave stories follow the OBS-006 Done story as the template: header table (Story ID / Status / Epic / **Depends on** / Dependency notes / Source / Size), then `executor`/`quality_gate`/`sdc_reviewer`/`quality_gate_tools`, Story, numbered **AC-n** items each ending in a bracketed source tag like `[design §4.2; security condition 1]`, Tasks mapped to ACs, Dev Notes with sources, Testing, CodeRabbit Integration, File List as proposed ownership, Dev Agent Record, QA Results, Change Log.

**Why:** @po validates with the 10-point checklist and Constitution Article IV (no invention) — every AC must trace to a decision, ADR/design section, review finding or existing spec; @qa reviews security stories against the security record's "Conditions for @sm" list, so each condition must appear verbatim as an AC and cite the record section (incl. "R1 delta check" tightenings). The wave planner (`aiox wave`, `wave-plan*.json`) **tokenizes the "Depends on" cell**, so it must contain only comma-separated story IDs; prose goes in a separate "Dependency notes" row (user instruction 2026-10-09). Open design questions are written to the stated default plus a "Decisions pending" table (question → default → ACs that change). When a story is re-cut after a product pivot (2026-10-09 ADR-SC-005 single path), the prior PO validation section is kept and headed "SUPERSEDED … historical", Status goes back to Draft, and the Change Log row explains the re-cut. Stories that the ADR allows to run in parallel (012B ∥ 013 ∥ 014) must have disjoint File Lists; the only sanctioned exception is the ADR's "one contract owner sequences result3/session-view3/pins" rule, which is labelled explicitly in both File Lists.

**How to apply:** When drafting or rewriting a story in docs/stories/STUDIO-OBSERVED/, reuse this shape, keep the Depends-on cell ID-only, tag every AC, carry security conditions verbatim, add Decisions pending for unanswered user questions, state file-list sequencing where stories share files and check parallel stories for overlap. Keep historical validations in `.ai/` referenced, never deleted. ADR-SC-005 is the canonical placement map for OBS-007/012A/012B/013/014/015/008/009/010/011; design R3 §10 differs from it on where the `/api/v1/studio` route move lives (ADR: 012A) — the ADR wins.
