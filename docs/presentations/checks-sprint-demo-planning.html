Current sprint · UI Studio

A written test can now run in a real browser and record what happened

  1. Prove it means what was written

    Before anything runs, the generated test is compared with what the author wrote, so it cannot quietly do something else. It is checked again just before it runs.

  2. Run it in a real browser

    A real, isolated browser performs the test and records a video, noting when each step happened.

  3. Never get stuck

    A run that hangs is stopped and cleaned up, and passwords and secrets never appear in the logs.

  4. Capture what happened

    Every run produces a result and a video recording of what happened.

Why it matters. A UI check now produces a video of what happened, so there is something to look at instead of only a status.

No demo this sprint. The first demo is planned for the next sprint demo.

UI Studio · The translation engine

The translation engine now reads the page, not just the words

  1. You write a step

    In plain English, the way you would explain it to a colleague.

  2. The page comes along

    With every step, Studio sends the page's HTML structure (its DOM) to the engine as context.

  3. The right action is chosen

    Knowing what is really on the page, the engine picks the right element and action. Results are more accurate and the experience is smoother.

We benchmark executions. Runs are measured, so we can tell how reliable the results are and whether the engine is getting better. Close to finished
