OBS-008 · Done

One Run control

The first Run learns the steps. Later Runs repeat them in seconds. Saved inputs and secrets are inserted without typing syntax, and a page that needs login says so in plain words.

OBS-015 · Done

Re-learn only what changed

Edit step 4 of 10 and the next Run replays steps 1–3 and learns from step 4 onward, not the whole test.

OBS-013 · Done

Video from the very first Run

The learning Run records video too, with every step and action seekable.

OBS-007 · Done

Login with secret references

Authors write login steps that reference saved credentials. A secret is filled only into the password field, at the step that calls for it, and never logged.

OBS-014 · Done

Safe by default

Every action the learning Run takes traces to what the author wrote, stays inside a policy the CSI owner controls, and is audited per CSI.

OBS-012A · OBS-012B · Done

One path only

The old compile-to-READY path is gone from backend, runner and frontend. Authors only see words about learning and repeating.
