FAQ

What goes to the model?
A text outline of the page and your step text, only while learning. Never screenshots, cookies or field values.
Do passwords go to the model?
No. Secrets are referenced by name and filled in only inside the runner. Use test accounts; pass credentials as secret references.
What if the app changes?
The run fails at that step, with video. Edit it to re-learn.
