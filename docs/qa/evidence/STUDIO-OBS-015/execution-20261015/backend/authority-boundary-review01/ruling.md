## Narrow failed-attempt qualifier and invariant composition

Inspected shared authority now reads every stored action; SUCCEEDED with dispatchCount1 passes the state gate. Anything else must satisfy `GuidedIncrementalStore.excluded(sessionId,actualLedger)` and the session-wide exclusion count must remain exactly at most1. This is the appropriate existing-semantics replacement for the old unconditional all-SUCCEEDED test. It is **not** a generic FAILED allowance and does not erase the failed row.

The qualifier first requires FAILED, TARGET_CHANGED, dispatchCount1, attemptOrdinal0. It then requires exactly one actual stored no-invocation receipt joined to this session's relearn switch by drift_receipt_hash, naming this exact admission with phase ADMITTED_PRE_INVOCATION. Receipt hash alone does not authenticate native history. Its validity composes with:

- V21 receipt PK is session_id: at most one receipt; switch PK is session_id. FKs bind request/preparation/action/session. Closed receipt CHECK requires nativeInvocationStarted=false, attemptOrdinal0, exact phase/admission null semantics and canonical receipt hash.
- Receipt INSERT trigger locks session, requires actual pending live REPLAYING_PREFIX, owning worker/fence, exact issued/prepared request context/input/source/config/program/evidence identity, original program operationHash, and for admitted phase the actual DISPATCHING/dispatch1 attempt0 plus exact consumed preparation/admission/coordinate/operation/context/input/evidence joins.
- Drift switch trigger joins the same receipt and coordinate, validates actual completed-prefix admissions; deferred receipt/switch guards require the atomic switch and FAILED/TARGET_CHANGED/dispatch1 settlement. Immutable receipt/switch/action terminal guards prevent later reuse or rebinding of those facts. attempt1 requires its original failed attempt+receipt+matching DRIFT switch; unique(session,step,ordinal,attemptOrdinal) bounds attempts.
- Backend prefixDrift authenticates the actual owning-worker role, name and fence under session lock; current access/source/materialization must hold, and the report must match the actual admitted ledger. Runner's monotonic journal writes REFUSED_BEFORE_INVOCATION only when nativeInvocationStarted remains false. Native-started/UNKNOWN_OUTCOME cannot become a lawful drift retry. These are existing authority roots, not assertions inferred from supplied JSON or the qualifier query alone.
- Complete commit reconstruction and the independent candidate lowerer retain the exact excluded action/preparation/obligation/request receipt and all raw graph facts; verifyExcluded checks the full receipt hash, phase/native flag, worker/fence/scope/session/context/input/preparation/coordinate/operation/request/association equalities. Missing successful actions, hidden preparations/admissions, changed old plan history, or altered private input documents cannot be excused merely because the state gate passed.

Consequences: missing receipt/switch, wrong session/admission/hash/phase, second excluded row, replacement attempt1 offered as excluded, dispatch0, pending ADMITTED/DISPATCHING, REVOKED, UNKNOWN_OUTCOME, assertion failure or policy failure all fail the state qualifier or full joins. A PRE_ADMISSION receipt has no admission and authorizes no failed action exclusion. Native-started evidence cannot acquire lawful stored no-native authority; a malicious returned/resealed receipt must fail actual immutable-row equality/authentication, not be accepted because it hashes correctly. SQL's broad deferred revision check for failed attempts is not a substitute for these stronger Java/native checks.

Historical18 qualification is exact: its reviewed positive has one genuine SUCCEEDED/dispatch1 navigation and no incremental state. Pending/UNKNOWN/other-failure documents fail the fast state checks without needing V21. Historical18 has no lawful admitted incremental exclusion. An artificial historical FAILED/TARGET_CHANGED/attempt0 shape is **not** a newly supported current incremental runtime subject; do not catch missing V21 relations or fake a receipt to make it work.
