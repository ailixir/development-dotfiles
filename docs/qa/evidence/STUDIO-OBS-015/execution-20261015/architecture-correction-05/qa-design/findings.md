## Proof requirements and refusal boundary

Presence is semantic: own retainedArtifact property iff exact runtime zero-transfer set Z is nonempty. Null/omitted proof on that branch, unnecessary proof on an ordinary graph, unknown fields, malformed extensions, caller expected hashes and generic trusted flags must fail before replay actions. Bound the combined frame before schema traversal and separately bound the frame with only retainedArtifact omitted and the Artifact3 preimage.

Use canonicalObserved/hashObserved directly: original array order, ASCII key ordering, exact strings/nulls, valid Unicode and safe integers. Require the complete artifact hash to equal the immutable Launch admission request artifactHash. Recompute learnedPlanHash/referencePolicyHash, check publicationEvidenceHash/configuration/profile and current scope equality as ruled. Historical learnedPlan.scopeHash and incremental.baseRevisionId are not this replay's scopeHash or current revisionId.

Require exact ordered equality for steps, guards, mapped bindings, transfers, and input metadata projection including secret referenceName. Released input values stay separate and undergo existing byte/type/origin/secret checks. No added/dropped/reordered action, guard, binding, input or transfer can gain authority by leaving a matching alternate copy in the artifact.

For Z derive exact empty-consumer artifact binding membership; require nonnull incremental data, unique actual learned action admissions, an ordered initial retained admission segment, actual read/provenance/sourceIntentStepId/coordinate/recipe/origin/guard joins, valid source-step boundaries and effective<=initial. Existing graph checks still account for every read and every binding-valued use. A retained read executes normally at its original coordinate and recaptures fresh withheld bytes; it is not deleted, skipped or replaced with a cached value.

Clarification of N05 and lifetime wording: Artifact3 is immutable revision data and contains no replay nonce. The exact same artifact bytes are valid in two separately admitted replays of the same finalized revision (P04). Reject a different artifact commitment, old Execute identities or old accepted Launch/context, and prevent state/context reuse after DONE. Do not reject equal witness bytes solely because a previous run also carried them. This interpretation follows the ruled commitment scheme and P04; it adds no schema field or broader authority.
