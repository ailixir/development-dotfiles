

## Outcome report validation placement — isolated source decision

The current outcomeV2 owner callback is source-bound; its exclusive validation cost is unknown. For a supported standard Jackson JSON request, the service may privately deep-copy the entire envelope and use that same owned tree for the original bridge/path validation, every digest/read and the original transaction. Unsupported/custom/opaque nodes retain the original path. Initial copy and fatal preparation failures are additional early observations, explicitly distinct from the original locked refusal timing.

Only the original ledger-schema validation may be prepared outside the owner lock, after the original bridge/path checks. A private-constructor ledger-owned token retains an inaccessible report snapshot, its exact serialized representation and a fixed success/error outcome. At the original ledger validation point, after all original fresh internal/materialization/path/action checks, accept a token only for that same ledger and an exact snapshot/representation match; otherwise perform the original validation. Known INVALID_CONTRACT/422 and RUNTIME_INCOMPATIBLE/409 outcomes are reconstructed there without retaining a Throwable. Unexpected nonfatal preparation failures select the original validation; Error propagates immediately. The public legacy verifier remains unchanged and no unproved after-schema helper is exposed.

Current stored-ledger identity/state/count checks, full context/session validation, saveAction validation, permissions/source/fence/expiry, digest/duplicate/accounting, winning audit/state writes, stop and transaction boundaries remain authoritative. The token proves input validation only, never current ownership, permission, use or replay authority. Its private copies add memory, matching and possible fallback work; no latency improvement or 1000 ms acceptance result is asserted. Existing defining tests cover token fallback/typed errors and preserve every old assertion; no new mandatory Core/browser case is introduced. Source review and coordinator-owned checks precede any integration.
