# DIAG-START-1 author design (before code)

Status: off-tree author proposal only, independent exact-diff review required. No runtime authority, QA verdict, lifecycle change or production application is claimed. The assigned architecture ruling is `t0/resume-architecture/resume2/review.md`, DIAG-START-1. Original B1 remains frozen; root owns B1/B7 reconciliation and permission to apply/run once.

Select only active guided C6 kind4 case epochs (the released-value injected-failure subject), producer1. This is the failed-start subject; selection is not based on private-values file existence. Maintain a diagnostic-only session-hash Map and runtime WeakMap, distinct from unchanged success-only revRuntimes. The canonical session hash includes JSON string quotes, matching contracts.hash. Ownership claim records begin before any runtime exists and share the session hash; context hash is initially the canonical null hash and is bound at START_BEGIN. The schema therefore retains each event's actual binding, never backfills a fictional context identity into early claims.

Integrate START_BEGIN/SETTLE in the existing revStart wrapper, STOP_ENTRY/SETTLE in revStop, CHECK_GRANT in revCheck and INVALIDATE in revInvalidate. Extend the injected fixture's existing wrapper mechanism for ownership requestClaim, stopEntry and close; original receiver/args/result promise and error are returned exactly once. Runtime startAbort.abort and applyAcknowledgedLease are wrapped only as owned INSTANCE descriptors before original start; no global AbortController/prototype modification. Diagnostic methods restore exact prior descriptors or delete previously absent own properties. Ownership close observation restores only diagnostic-owned descriptors; it does not touch native wrappers or grant authority. No revStarted/revRuntimes/native/cleanup flag is set early.

Capture stop/abort origin from a static exact-line dist allowlist with per-file SHA256 checks. Frames are inspected only in memory; exported origin/site are closed enum/integer. Ownership stopEntry records its original caller provenance before its Promise.resolve().then(stop) hop and hands that provenance to its runtime. Runtime stop propagates it only within the synchronous original invocation to the instance abort observer. Runtime timer, startup-catch and browser-loss sites have separate IDs. Unmapped/ambiguous frames remain OTHER/site0; hash mismatch marks instrumentationFailed and forbids a trusted site classification. First abort records first=true and signal.aborted before forwarding; repeated stops use an incrementing numeric count. Preserve original closing promise; observers attach settlement callbacks without replacing it.

Claims report the original requestClaim arithmetic (lease-now-100, min with 1000/10000), original budget and lease/assignment deltas, initial flag, stopped/epoch, duration, closed result/code. checkGrant records actual returned-grant advancement; applyAcknowledgedLease observes runtime installation. A requestClaim's controller is private and locally constructed; observe its signal via the EXISTING options.claim argument by an owned instance options.claim wrapper. Attach/remove a once abort listener around that original call, never wrap AbortController globally. If the original claim call returns before a later requestClaim timeout, the signal listener must remain until requestClaim settles; accounting and removal belong to requestClaim settlement. This is only an observation of the original signal, not an additional claim or renewal.

Closed schema: schemaVersion,event,seq,sessionHash,contextHash,case,epoch,producer,elapsedMs,durationMs,phase,loss,reason,code,origin,site,leaseRemainingMs,assignmentRemainingMs,budgetMs,leaseAdvanceMs,entryEpoch,stopped,aborted,initial,fulfilled,first,stopCount,chain0..chain5,launchPhase,launchLoss. Fixed strings are exclusively enum values or SHA256 lowercase hex. All timing is finite bounded integer deltas, elapsed monotonic. No raw error, message, stack, identities, values, references, bodies, paths or URLs leave memory.

At most32 events and16384 total bytes per selected case INCLUDING fixed ledger metadata/truncation/instrumentationFailed flags. Reserve metadata space; overflow sets truncated and never replaces earlier events. Snapshot writes are synchronous bounded private file writes, so there are NO asynchronous diagnostic writer promises to abandon at process.exit. Do not await log writes in start/stop; original call/result remains untouched even if logging fails. Account attempted/completed/failed/pending writes in the envelope; pending is actual zero only after the synchronous write closes. One open descriptor per snapshot is closed in finally. Use existing revCheckRoot (owned0700/no-symlink/uid root), fixed numeric filenames, O_NOFOLLOW|O_EXCL mode0600 temporary, checked prior target, exact owner/mode checks, rename only inside root. Only value-free ledgers are added to the existing final sink scan; existing scans/oracles remain. Unexpected process death/no close ledger is incomplete diagnosis.

Close fulfillment/rejection is observed before the caller's await continuation. Exact own descriptors and diagnostic prototype descriptors are restored there, only if still equal to our wrapper. The ledger records restoration result and writer completion; refusal marks instrumentationFailed without authorizing cleanup or changing original close result. A ledger is complete only after original ownership close fulfilled AND restored=true AND writersPending=0 AND failed=0 AND truncated=false. No deadline, timer, callback result, provider operation, retry, native kill or quarantine changes are permitted.
