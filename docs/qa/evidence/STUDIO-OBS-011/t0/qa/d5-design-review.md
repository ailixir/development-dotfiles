# 11-IT-R D5 independent design assessment

Quinn (@qa), 2026-10-18, source-frozen T0. Read-only design review of `t0/early/11-IT-R/it-r-prep.json`, the actual ReplayIT source, lane plan and story AC-5 TEST-001. **No final lane-exit co-sign, runtime proof or story verdict.**

## Design verdict

**Conditional design co-sign for the complete-lane audit invariant; unconditional “not weaker” is withheld until lane exit.** The split is a reasonable way to separate whole-class corpus controls from a single case's content checks, and D1 adds each C5 capture's actual canaries to the registry. The full-lane endpoint can retain exactly today's non-empty-canary, admitted-event, dispatched-event, closed-key-set, 1 KiB and absent-canary assertions. This is not proof that the proposed implementation retains them, nor proof that every single-test invocation is independent.

The present proposal has two concrete proof gaps: `wholeLaneRan()` checks only method names, and its only gate mutant forces true on a subset. A set of 28 incremental method names can exist after only one of the parameterized method's 35 variants. That is not the complete 62-case incremental lane. Conversely a false predicate could bypass the full-lane controls and the proposed mutant would not detect it. The lane must close these gaps or carry D5 as unresolved by name.

## Conditions for the lane-exit “not weaker” co-sign

1. **Content stays unconditional at every existing scan boundary.** The complete loop over actual audit events, closed key order, rendered-byte bound and absence of all registered actual canaries remains byte-equivalent in asserted meaning. C5 scans still happen before private deletion/wiping; final scans still include context-destruction writes. D1 must register values before any relevant producer starts and retain those values until final class scans. No exception swallowing or broader logger filter.
2. **Complete-lane controls cannot silently disappear.** Use the actual profile's exact method/variant invocation multiset, not only a method-name set, to substantiate completeness at the final boundary: default 46 cases; incremental 27 singleton cases plus all 35 named parameterized variants = 62 cases. Independent archive/count reconciliation must still detect missing, repeated, skipped and failed cases. If `wholeLaneRan()` remains a coarser method-set helper, it cannot be the only evidence of completeness: add an explicit exact final invocation assertion for credited full-lane runs and prove the controls execute. Incomplete/subset invocation is named as such, never presented as a credited full class.
3. **Account for the earlier C5 positive-control timing.** D5 deliberately removes the class-wide admitted/dispatch/non-empty controls from mid-class C5 closes. The registry and event list are retained until the final scans, so final content checks can cover the same earlier bytes. The receipt must explicitly document this temporal change and prove those final controls and scans run before any evidence is discarded. It must not claim each subset still proves the whole-class admitted+replay corpus. If the earlier boundary is itself required by an inherited criterion, retain an appropriate actual local observation control there, or carry the independence claim for that case; root's provisional acceptance is not evidence that a weakened security boundary is allowed.
4. **Order 39 is named correctly.** `auditStreamCarriesIdsAndCodesOnlyAcrossTheWholeClass` alone produces no corpus. A post-split green-alone result would be vacuous for its whole-class claim. Either make it independently establish a genuine corpus or carry this exact test by name, owner @dev, reason class-scoped corpus assertion. The story explicitly allows named carries; never describe that case as independently proven.
5. **Runtime evidence remains owed.** Preserve red-first evidence for the existing alone-run failures, each P7 alone, the relevant reverse-order run, Orders 2/3 alone and reversed for D2–D4, and the complete two-task class runs. These diagnostic subset runs receive no D-14 gate credit. The baton requires two consecutive full-class green runs on identical ReplayIT bytes; retain the unchanged per-name method/variant lists and wrapper-only diagnostic. The six unprovable POLL ids remain named carries unless separately proved.
6. **Strengthen the planned mutation evidence.** Keep M-gate=true on a subset, but also establish that the real final complete-lane predicate is true for both actual task profiles and that each vacuity-control failure (empty canaries, missing admitted events, missing dispatch events) still produces red at the final whole-lane boundary. The exact invocation check must reject an omitted or duplicate parameterized variant. Verify that a canary-containing event, changed key shape and >1 KiB event still fail the content scanner; existing equivalent independent scanner controls can be cited by exact case instead of redundant new runs. Mutations stay within one lock hold/scratch copy and restored SHA must equal the pre-mutation SHA.

These conditions derive from TEST-001 b's “asserted behaviour is not reduced”, the existing scanner boundaries, the declared exact test list, and the lane's “green twice” rule. No new feature or external-provider proof is requested.
