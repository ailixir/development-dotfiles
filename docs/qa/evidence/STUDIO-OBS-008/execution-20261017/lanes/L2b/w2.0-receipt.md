## Decisions where the plan sketch and the contract differ (contract wins)

- `GuidedError` requires `requestId`, `retryable`, `messageCode`; there is no `reason` field.
- Public finalize body is `{schemaVersion, expectedSourceRevision, expectedConfigurationRevision}`, not the bridge `finalize` (ownerFence, hashes).
- Clarify body is `{schemaVersion, clarificationId, choiceId, generation}`; `answer(choiceId)` will read the other two from the pending question.
- Start hints `baseRevisionId` / `firstLearnStepId` are independent optionals.
- `apiClient` drops the HTTP status, so `readResult` uses a per-request `transformResponse` that wraps 2xx bodies with the status (axios 1.11). `apiClient.ts` is untouched.

Invented-but-flagged, open to amendment at the body step: `GuidedPendingReason` (`REAUTHENTICATION_REQUIRED`, `NOT_READY`, `PUBLICATION_PENDING`) and `GuidedStartRefusal` shape. The full list of `[AUTO-DECISION]` entries is in the JSON receipt.
