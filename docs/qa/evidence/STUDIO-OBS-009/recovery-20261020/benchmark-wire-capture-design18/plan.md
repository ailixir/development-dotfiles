# GAP16-01 wire-response capture design18

Recommend a private per-run public-client binding with synchronous transient scanning of consumed response text, plus explicit local observation completeness. This closes the accepted error-path observation gap without a global collector or new public caller configuration. Independent design review is next; this directory contains no implementation or executed proof.

The actual public client is privately registered in a WeakMap with a factory bound to its original transport/base/token/scope settings. Each driveCase/driveIncremental invocation obtains its own observed clone and copied canary set. Shared original clients therefore do not share an observer slot. Programmable doubles keep their existing fulfilled-value behavior; unobservable raw transport remains explicitly UNOBSERVABLE. No checker/hook is exported or required in caller business input.

For every real adapter call, register the attempt; when response.text returns, synchronously scan that entire already-consumed string before size, JSON or HTTP rejection. Retain only fixed-label/canary-index/hash-prefix/hit aggregates and closed counters. Use existing encoded-variant matching with non-copying non-overlap searches for over-bound text, not a body queue or split-derived raw reservoir. Exactly2,000,000 UTF-16 units is still allowed; larger responses still fail. A tail canary beyond the limit is inspected before the fixed refusal. Existing response.text allocation-before-bound behavior is unchanged; this is not a streaming-memory guarantee. Failed/partial body reads or scan failures produce unknown coverage, not an empty body. Successfully decoded bodies continue in full through the existing wrapper before FR06 tuple checks. A rejected raw body never masquerades as an acknowledged start reply.

Errors retain fixed messages, numeric status and recognized source-literal protocol codes, including STALE_REVISION. Unknown strings/objects in code/error, raw parser/transport diagnostics, statusText, hint, response objects and original causes must not escape. A closed map from existing v3/legacy route literals preserves recognized vocabulary; arbitrary legacy free text becomes null. This is required privacy narrowing, not a backend/error-vocabulary change or a regex that admits body secrets.

Raw observation only accumulates closed facts. It must not latch STOPPED_HARD_GATE before interruptedRun accounts for already known or potentially started sessions. Preserve that accounting first, then merge findings and latch: an unacknowledged canary/error start still gets one conservative potential-start charge and unknown usage; a failed post-base GET/PUT retains one base charge, no suffix,409 retry or extra model/session charge. Keep all FR06 revision/guided-string/at-most-once/deadline semantics.

Carry the configured extraTexts collector into interruption instead of forcing null. Keep normal collection stages; collect at most once for a new admitted interruption stage, and do not retry a collector/scanner stage that already failed. Preserve earlier hits and sticky unknown scope; never mask an original API failure with raw collector errors. Scan valid supplied strings even if another field is malformed. Labels are fixed/declared aliases, not body/exception text. A missing hook is NOT_CONFIGURED and never a global zero. No new provider/network collection or timeout policy is introduced; actual independent collectors/readsets must be finite and owner-admitted. All final collection/recovery is awaited before finally disposes only that run's transient state; do not return an unawaited recovery promise and clear its observer too early.

Use one closed row in existing details.canaryObservation for publicHttp status, attempt/fully-consumed/scanned counts, fulfilled-value status and configured-extra-text status/counts. Missing or malformed required local facts are unknown. Do not overload learnSessionsComplete or the three CauseAssessment fields. The existing driverObservations/OBSERVATION_UNAVAILABLE path and a narrow existing-validator problem must prevent D_C GATE_PASS on unknown local capture across ALL attempts, including excluded earlier attempts. Keep hardGates' numeric known-positive counts/shape; add only a small scoped summary with complete, knownLeakRuns, totalLeakRuns:null when incomplete, unknown identities and globalWireComplete:null. Empty populations stay incomplete. Default CLI's unprovided global gateway/log/SSE/audit/human collection remains an external gate even when local public-response scanning is complete.

Four existing targets are justified: evaluate.mjs, evaluate.d.mts, harnessSelfTest.test.ts and observedCorpus.ts. The fourth only makes syntheticRuns' UNIT-ONLY complete-observation premise explicit, so current scoring assertions remain intact without grandfathering missing real coverage. All four remain within the already adopted ten paths. No semantic corpus validator or stop-rule implementation change is proposed. The all-local aggregate test uses an in-memory clone of existing23 known-local cases with derived arithmetic/sessionPlan/digest recomputed; actual corpus/staging facts are untouched.

Eight groups from independent QA prep19 are bound in findings.json: non2xx/malformed/raw-code privacy; exact bound and consumed tail; body/scanner unavailability; interrupted collector canary/failure/no retry; known/potential-start accounting; otherwise>=90% full population unable to pass with one unknown/missing/earlier-excluded capture; and two interleaved drivers sharing the actual public client with distinct canary sets/cleanup. The latter must exercise real factory identity, not only composed forwarded methods. Existing31 FR06/group5 controls stay, plus new WIRE-OBS18 cases. All31 existing benchmarkScoring cases are affected by buildBenchmark/syntheticRuns and join future checks. Type-check and four-file lint apply; no blanket105/oldRED/native/backend/diagnostic repeat. If a later implementation changes stop-rule or validator semantics, its actual extra test scope must be named first.

A future four-target transaction needs fresh exact preimages/modes, candidate source QA and a new root admission; old execution05/adoption09 must not be replayed. New evaluator pins require the already reviewed finite original freeze-first/validate sequence and honest manifest/source captures, with nonderived data exact and no SDK seed/build/privateMF transplant. Existing31, failure10, proof12, old105 and original corpus09/applicability14 remain qualified history. This design supplies no actual source, runtime, provider, budget, human or lifecycle authority.
