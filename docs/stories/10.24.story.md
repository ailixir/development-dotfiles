## Story

## Acceptance Criteria
1. Capture inputs/IDs/scope/configuration and compile identity atomically before network work; race tests prevent old inputs from receiving new revision tags.
2. Unsupported/clarification prevents the whole executable candidate; strict validator envelopes reject missing/contradictory versions, steps or outcomes.
3. Implement versioned authoring IDs and scope reaffirmation; legacy/structural/ambiguous/incompatible cases select full with reason; no-op saves preserve confirmation.
4. For eligible passing baseline, diff all edits and regenerate conservative affected suffix; last independent edit generates only last step; unknown backward/global scope selects full.
5. Validate closed patches against exact writable IDs; preserve reused source/code byte-for-byte; server derives positional fields; whole merged artifact always validates.
6. Preserve request budgets on repair and reject invalid reuse without silently widening authority; compatible configuration-only/revert cases use zero inference with new confirmation and evidence.
7. Publish immutable mixed provenance only while current; distinct identical-output requests and repeated same-request publication follow C0 identity rules.
8. Confirmation binds exact source/config/scope/candidate; compile/save never runs browser; explicit Run executes full fresh workflow. Cross-CSI and revoked access cannot reuse baselines.
9. Cover plan acceptance 1–10, 13–16, 18 and 20 with meaningful unit and real-database concurrency tests; incremental defaults disabled pending evaluation.
