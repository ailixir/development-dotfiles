## User Story

**As a** frontend developer preparing to replace MSW mocks with real backend calls,
**I want** the API client, dev server proxy, and response normalization aligned with the backend's `/api/v1` contract,
**so that** subsequent domain stories can wire to real endpoints with zero URL/format mismatch.

- [x] **AC-1:** `APP_CONFIG.apiBaseUrl` changed from `/api` to `/api/v1` in `appConfig.ts`. `VITE_API_BASE_URL` default updated in `.env.development`.
- [x] **AC-2:** All `API_ENDPOINTS` constants remain relative (e.g., `/checks`, `/csi/search`). The apiClient concatenates `baseURL + endpoint` → `/api/v1/checks`. No endpoint constant changes needed.
- [x] **AC-3:** All MSW handler URL patterns updated from `/api/...` to `/api/v1/...` (e.g., `http.get('/api/checks', ...)` → `http.get('/api/v1/checks', ...)`). - [x] **AC-4:** Vite dev server proxy configured in `vite.config.ts`: `/api/v1` → `http://localhost:8080/api/v1` (passthrough, no path rewrite). Enabled only when `VITE_ENABLE_MSW !== 'true'` or when a domain is in `VITE_DISABLE_MSW_DOMAINS`.
- [x] **AC-5:** Webpack dev server proxy configured in `webpack.config.js` (or `devServer` section): same `/api/v1` → `http://localhost:8080/api/v1` proxy rule.
- [x] **AC-6:** Response normalization utility `normalizePageResponse<T>(springPage)` created in `src/services/api/responseAdapter.ts`. Transforms Spring Page `{content, number, size, totalElements, totalPages}` → FE `ApiResponse<T[]>` `{data, page, limit, total, totalPages}`. Handles: 0-based→1-based page conversion, `content`→`data` rename, `size`→`limit` rename, `totalElements`→`total` rename.
- [x] **AC-7:** `normalizePageResponse` also handles the case where the backend returns the FE format directly (passthrough) — defensive for endpoints that don't use Spring Page.
- [x] **AC-8:** `VITE_DISABLE_MSW_DOMAINS` env var documented with cutover sequence comment in `.env.development`: `# M3 cutover: 3.2=checks, 3.3=csi, 3.4=schedules, 3.5=users. Full: VITE_ENABLE_MSW=false`.

## Implementation Notes

### MSW handler update pattern
```typescript
// Before
http.get('/api/checks', async ({ request }) => { ... })

// After
http.get('/api/v1/checks', async ({ request }) => { ... })
```

### Response adapter
```typescript
interface SpringPageResponse<T> {
  content: T[];
  number: number;      // 0-based page
  size: number;
  totalElements: number;
  totalPages: number;
}

export function normalizePageResponse<T>(raw: any): ApiResponse<T[]> {
  if (raw.content !== undefined) {
    return {
      data: raw.content,
      page: raw.number + 1,
      limit: raw.size,
      total: raw.totalElements,
      totalPages: raw.totalPages,
    };
  }
  // Already in FE format (from MSW or non-paged endpoint)
  return raw;
}
```

### Vite proxy
```typescript
// vite.config.ts
server: {
  proxy: {
    '/api/v1': {
      target: 'http://localhost:8080',
      changeOrigin: true,
    }
  }
}
```
