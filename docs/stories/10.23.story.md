## Acceptance Criteria
1. Add forward-only migration for C0 stable IDs/source/scope snapshots, candidate request identity and mixed provenance with database-enforced immutability.
2. Distinct explicit compile requests with identical artifact bytes have separate candidate confirmation lifecycles; same request publication is idempotent.
3. Select same-test/CSI confirmed baselines from exact successful full execution identity with deterministic indexed ordering; absent/expired evidence is ineligible.
4. Protect source/configuration/scope revisions and current request against stale publication; retain original generating provenance for reused steps.
5. Test fresh and upgraded/legacy databases, immutable-field tampering, realistic baseline selection and mixed-writer cutover; document compatible rollback floor.
