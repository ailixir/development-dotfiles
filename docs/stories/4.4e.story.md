## User Story

**As a** report delivery system,
**I want** a `ReportMailSender` that sends rendered HTML reports via the enterprise SMTP relay to a list of recipients,
**so that** report email delivery is encapsulated in a single, testable component with per-recipient success/failure tracking.

---

## Acceptance Criteria

### Mail sender component

- [x] **AC-1:** `ReportMailSender` in `reports/mail/` package with `@Component` and `@ConditionalOnProperty(name = "spring.mail.host")` (only loads when SMTP is configured).
- [x] **AC-2:** `SendResult send(String reportName, String html, String[] recipients)` method.
- [x] **AC-3:** Creates one `MimeMessage` per recipient (not BCC) for individual delivery tracking.
- [x] **AC-4:** Email subject format: `"[PUT Checks] {reportName} — {yyyy-MM-dd}"`.
- [x] **AC-5:** Email content type: `text/html; charset=UTF-8`.
- [x] **AC-6:** From address configurable via `checks.reports.mail.from` (default: `put-checks-noreply@citi.com`).

### Partial failure handling

- [x] **AC-7:** `SendResult` record with `int sent`, `int failed`, `List<String> failedRecipients`.
- [x] **AC-8:** Individual recipient failures are caught, logged, and added to `failedRecipients`. Other recipients still receive the email.
- [x] **AC-9:** If ALL recipients fail, `SendResult.sent == 0` and the caller can determine status accordingly.

### Configuration

- [x] **AC-10:** SMTP configuration in `application.yml`:
  ```yaml
  spring.mail.host: ${SMTP_HOST:}
  spring.mail.port: ${SMTP_PORT:25}
  spring.mail.properties.mail.smtp.starttls.enable: true
  spring.mail.properties.mail.smtp.connectiontimeout: 5000
  spring.mail.properties.mail.smtp.timeout: 10000
  ```
- [x] **AC-11:** Mail sender does NOT load when `spring.mail.host` is empty/absent (conditional bean).

### Tests

- [x] **AC-12:** `ReportMailSenderTest` (unit test with mocked `JavaMailSender`):
  - Sends to 3 recipients, all succeed — `sent=3, failed=0`.
  - Second recipient throws `MailSendException` — `sent=2, failed=1, failedRecipients=["bad@citi.com"]`.
  - All fail — `sent=0, failed=3`.
  - Subject format verified.
  - HTML content type verified.

## Implementation Notes

- **No BCC:** Per-recipient `MimeMessage` enables individual delivery tracking. BCC would send one email but lose granularity on which recipients failed.
- **`@ConditionalOnProperty(name = "spring.mail.host")`:** In local dev without SMTP configured, the mail sender bean won't exist. The delivery service (4.4f) should handle this gracefully (log a warning, skip SMTP send, still persist the `ReportExecution` audit record).
- **Spring Mail dependency:** `spring-boot-starter-mail` should already be in `build.gradle.kts` or needs to be added.
