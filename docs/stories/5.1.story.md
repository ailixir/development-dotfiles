**I want** `./gradlew check` to pass with zero test failures,

---

## Problem Statement

Commit c4b8a0f25 ("wired front and back") introduced `LocalDevAuthFilter` — a development-only filter (`@Profile("local")`) that injects a default authenticated identity, bypassing `BffSessionAuthenticationFilter`. This breaks 8 integration tests that test security behavior:

1. **BffFilter tests** (3 tests): Expect BFF filter to handle core-service errors (503) and unauthenticated requests (401). `LocalDevAuthFilter` pre-authenticates before BFF runs, so the filter never triggers.
2. **Permission/ownership tests** (5 tests): Expect `checks-admin` vs non-admin behavior or CSI ownership enforcement. `LocalDevAuthFilter` always injects `checks-admin` role with no CSI ownership, changing expected outcomes.

Additionally, 46+ tests get `initializationError` when the full suite runs (all pass individually). This is Spring context cache saturation — too many distinct `@DynamicPropertySource` configurations create separate contexts that exhaust embedded Postgres connections.

## Implementation Notes

### LocalDevAuthFilter gating

```java
@Component
@Profile("local")
@ConditionalOnProperty(
    name = "checks.local-dev-auth.enabled",
    havingValue = "true",
    matchIfMissing = true)
public class LocalDevAuthFilter extends OncePerRequestFilter { ... }
```

Tests that need to bypass: `@TestPropertySource(properties = "checks.local-dev-auth.enabled=false")`

### Context cache optimization strategies

1. Tests using identical `@ActiveProfiles` + `@DynamicPropertySource` values share contexts.
2. Tests that only differ by WireMock port already use dynamic ports — these should share context if grouped correctly.
3. Consider using `@Nested` or `@ContextConfiguration` to share expensive contexts.
4. Reduce the number of embedded Postgres instances by identifying test classes that can share a single context.

### Root cause of each assertion failure

| Test | Expected | Actual | Root Cause |
|------|----------|--------|------------|
| BffFilter503IT | 503 | 404 | LocalDevAuthFilter bypasses BFF; request hits Spring router (no endpoint for /api/v1/test) |
| BffFilterHappyPathIT | 200 with BFF auth | 200 with dev auth | LocalDevAuthFilter provides identity before BFF runs |
| BffFilterUnauthIT | 401 | 200 | LocalDevAuthFilter provides identity; no unauthenticated scenario possible |
| CsiFetchIT.fetchWithoutOwnership | 403 | 200 | Dev identity has checks-admin role; might bypass ownership check |
| BulkDeleteIT.allUnowned | 400 | different | Dev identity has checks-admin; bypasses ownership validation |
| BulkDeleteIT.mixedOwnership | 207 | different | Same as above |
| IdempotencyFilterIT.fourxx | 4xx cached | different | Auth context changed by dev identity |
| RateLimitFilterIT (4 tests) | Rate limited | different | Auth context changes rate limit classification |
